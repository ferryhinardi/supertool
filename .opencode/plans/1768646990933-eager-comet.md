## Tool Features

### 1. URL Encoder/Decoder
- 4 encoding methods: `encodeURI`, `encodeURIComponent`, `decodeURI`, `decodeURIComponent`
- Batch processing support
- Copy to clipboard
- Clear descriptions for each method

### 2. Case Converter
- Supports: camelCase, PascalCase, snake_case, SCREAMING_SNAKE_CASE, kebab-case, TRAIN-CASE, dot.case, Title Case, Sentence case, lowercase, UPPERCASE
- Preview all conversions at once
- Batch convert multiple lines

### 3. Random Generator
- Random numbers (integers, floats with range)
- Random strings (configurable charset)
- UUIDs (v4)
- Passwords (configurable length, special chars)
- Generate multiple at once

### 4. Countdown Timer
- Select target date/time
- Shows days, hours, minutes, seconds remaining
- Handles past dates gracefully
- Optional event name
