## Recommended New Tools (Priority Ordered)

### 🔥 HIGH PRIORITY (High demand, broad appeal)

#### 1. Citation Generator
- **Category:** Productivity
- **Target Users:** Students, researchers, academics, writers
- **Features:**
  - Support APA, MLA, Chicago, Harvard, IEEE formats
  - Auto-detect source type (book, article, website, video)
  - Batch citation generation
  - Export to Word/BibTeX
- **Complexity:** Medium
- **Why:** One of the most searched-for tools by students

#### 2. AI Content Detector
- **Category:** Productivity
- **Target Users:** Teachers, editors, content managers, HR
- **Features:**
  - Detect AI-generated text (GPT, Claude, etc.)
  - Sentence-by-sentence highlighting
  - Confidence score
  - Supports multiple languages
- **Complexity:** Medium (can use external APIs)
- **Why:** Extremely high demand with AI explosion

#### 3. Text-to-Speech Generator
- **Category:** Media
- **Target Users:** Content creators, accessibility needs, language learners
- **Features:**
  - Multiple voices and languages
  - Adjustable speed and pitch
  - Download as MP3/WAV
  - SSML support for advanced control
- **Complexity:** Medium (Web Speech API or cloud TTS)
- **Why:** Accessibility and content creation crossover

#### 4. Social Media Image Resizer
- **Category:** Design
- **Target Users:** Marketers, social media managers, influencers
- **Features:**
  - Presets for all platforms (Instagram, Facebook, Twitter, LinkedIn, TikTok, YouTube)
  - Batch resize
  - Smart crop with face detection
  - Export all sizes at once
- **Complexity:** Low-Medium
- **Why:** Every social media user needs this

#### 5. Business Name Generator
- **Category:** Productivity
- **Target Users:** Entrepreneurs, startups, small business owners
- **Features:**
  - AI-powered suggestions based on industry/keywords
  - Domain availability check
  - Social handle availability
  - Save favorites
- **Complexity:** Medium
- **Why:** Starting a business is universal

#### 6. Hashtag Generator
- **Category:** Productivity
- **Target Users:** Social media managers, influencers, marketers
- **Features:**
  - Generate relevant hashtags from image/text
  - Trending hashtags by category
  - Copy sets for different platforms
  - Hashtag analytics (popularity score)
- **Complexity:** Low-Medium
- **Why:** Daily need for social media users

## Technical Considerations

### New Dependencies to Consider
- **TTS/STT:** Web Speech API (free) or Google Cloud/AWS (paid, better quality)
- **AI Detection:** GPTZero API, Originality.ai, or build custom model
- **Image Processing:** Sharp.js (already likely used), Fabric.js for canvas
- **Citation:** Citation.js library or CSL (Citation Style Language) processor

### Potential New Category
Consider adding a **"Lifestyle"** or **"Everyday"** category for tools like:
- Cooking Unit Converter
- Fuel Cost Calculator
- Event Countdown Timer
- Name Generator
