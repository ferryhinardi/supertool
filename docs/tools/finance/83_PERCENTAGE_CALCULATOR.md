## Key Features

### 1. **Seven Calculation Modes**

**Mode 1: "What is X% of Y?"**
- Calculate a percentage of any number
- Example: What is 25% of 200? = 50
- Formula: `(25% ÷ 100) × 200 = 50`
- Use case: Finding discount amounts, portions, fractions

**Mode 2: "X is what % of Y?"**
- Find what percentage one number is of another
- Example: 50 is what % of 200? = 25%
- Formula: `(50 ÷ 200) × 100 = 25%`
- Use case: Calculating completion rates, ratios, proportions

**Mode 3: "X is Y% of what?"**
- Find the whole when you know a part and its percentage
- Example: 50 is 25% of what? = 200
- Formula: `50 ÷ (25% ÷ 100) = 200`
- Use case: Reverse-engineering totals, finding original prices

**Mode 4: "Percentage Change"**
- Calculate increase/decrease between two values
- Example: 100 → 150 = +50% increase
- Formula: `((150 - 100) ÷ 100) × 100 = 50% increase`
- Use case: Growth rates, price changes, financial trends

**Mode 5: "Discount Calculator"**
- Calculate final price after discount
- Example: $100 with 20% off = $80 (saved $20)
- Formula: `$100 - ($100 × 20%) = $80 (saved $20)`
- Use case: Shopping, sales events, price comparisons

**Mode 6: "Tip Calculator"**
- Calculate tip amount and total bill
- Example: $100 bill with 15% tip = $115 total
- Formula: `Bill: $100 + Tip: $15 (15%) = Total: $115`
- Use case: Restaurants, delivery services, service gratuities

**Mode 7: "Tax Calculator"**
- Calculate price with tax included
- Example: $100 with 8% tax = $108
- Formula: `Price: $100 + Tax: $8 (8%) = Total: $108`
- Use case: Retail purchases, online shopping, budgeting

## Tips & Best Practices

### Input Techniques

**1. Use Decimal Values for Precision**
- Enter 3.5% as 3.5, not just 3 or 4
- Enter $49.99, not $50 (if exact amounts matter)
- Calculator handles up to many decimal places

**2. Understand Percentage vs. Decimal**
- Enter percentage as whole number (25 for 25%)
- Don't enter 0.25 (calculator will interpret as 0.25%)
- System automatically converts to decimal for calculation

**3. Use Tab Key for Quick Input**
- Press Tab to move between fields
- Faster than clicking with mouse
- Result updates automatically

**4. Don't Use Currency Symbols**
- Enter 100, not $100 (calculator adds $ in result)
- Applies to discount, tip, and tax modes
- Symbol appears automatically in formula display

### Mode Selection Tips

**5. Pick the Right Mode**
- **Known**: Percentage and base → Mode 1 (X% of Y)
- **Find Percentage**: Part and whole → Mode 2 (X is what % of Y)
- **Find Base**: Part and percentage → Mode 3 (X is Y% of what)
- **Compare Values**: Old and new → Mode 4 (Percentage Change)
- **Shopping**: Price and discount → Mode 5 (Discount)
- **Dining**: Bill and tip rate → Mode 6 (Tip)
- **Checkout**: Price and tax rate → Mode 7 (Tax)

**6. Use Percentage Change for Growth Rates**
- Stock prices, sales growth, population changes
- Shows positive (+) for increases, negative (-) for decreases
- More accurate than manual calculation

**7. Use Discount Calculator for Stacking Discounts**
- Apply first discount
- Copy result
- Use result as "Original Price" for second discount
- Example: 20% off, then 10% off = two separate calculations

### Accuracy Tips

**8. Round at the End, Not During**
- Enter exact values (49.99, not 50)
- Let calculator handle decimal precision
- Only round final result if needed

**9. Verify Percentage Change Direction**
- Positive (+) = increase
- Negative (-) = decrease
- 100 → 150 = +50% (not 50%)
- 150 → 100 = -33.33% (not -50%)

**10. Check Formula for Understanding**
- Formula display shows exact calculation
- Helps catch input errors
- Educational tool for learning percentage math

### Practical Shopping Tips

**11. Compare Discount Types**
- "$20 off" vs. "20% off" → Use both modes to compare
- Mode 1: What is 20% of [price]?
- Manual: Compare to $20 flat discount
- Pick whichever saves more

**12. Calculate Multi-Item Discounts**
- "Buy 2, get 30% off" → Calculate per-item savings
- Total price ÷ 2 = per-item price
- Then apply 30% discount

**13. Account for Tax After Discount**
- Calculate discount first (Mode 5)
- Use discounted price for tax calculation (Mode 7)
- Tax applies to post-discount price in most places

### Tip Calculator Tips

**14. Use Standard Tip Rates**
- 15%: Standard service
- 18-20%: Good service
- 22-25%: Excellent service
- 10%: Poor service (or explain issue to manager)

**15. Tip on Pre-Tax Amount**
- Use bill amount before tax for tip calculation
- More accurate and standard practice
- Example: $50 bill + $4 tax → Tip on $50, not $54

**16. Round Up for Convenience**
- $23.46 → Leave $25 for cleaner math
- Makes splitting bills easier
- Server appreciates whole numbers

### Calculation Formulas

**Mode 1: What is X% of Y?**
```javascript
result = (percent / 100) * number
Example: (25 / 100) * 200 = 50
```

**Mode 2: X is what % of Y?**
```javascript
result = (number / total) * 100
Example: (50 / 200) * 100 = 25%
```

**Mode 3: X is Y% of what?**
```javascript
result = (number / percent) * 100
Example: (50 / 25) * 100 = 200
```

**Mode 4: Percentage Change**
```javascript
change = ((newValue - original) / original) * 100
Example: ((150 - 100) / 100) * 100 = 50%
```

**Mode 5: Discount Calculator**
```javascript
discountAmount = (discount / 100) * price
result = price - discountAmount
Example: 100 - (20/100 * 100) = 80
```

**Mode 6: Tip Calculator**
```javascript
tipAmount = (tipPercent / 100) * bill
result = bill + tipAmount
Example: 100 + (15/100 * 100) = 115
```

**Mode 7: Tax Calculator**
```javascript
taxAmount = (taxRate / 100) * price
result = price + taxAmount
Example: 100 + (8/100 * 100) = 108
```

## Troubleshooting

### Issue 1: Result Not Showing

**Symptoms**:
- Entered values but no result appears
- Result area blank

**Solutions**:
1. **Enter Both Values**
   - Both input fields must have values
   - One input won't trigger calculation

2. **Check for Valid Numbers**
   - Don't use letters or symbols (except decimal point)
   - Enter 25, not "twenty-five"
   - Enter 10.5, not 10,5 (use period, not comma)

3. **Avoid Division by Zero**
   - Mode 2 requires non-zero "Of Number"
   - Mode 3 requires non-zero percentage
   - These return no result if denominator is zero

### Issue 4: Percentage Change Shows Wrong Direction

**Symptoms**:
- Increase shows as negative
- Decrease shows as positive

**Solutions**:

**Example**:

```
50 → 100 = +100% (doubled)
```

## FAQ

### Q1: Can I calculate multiple discounts (stacked discounts)?

**Answer**: **Not in a single calculation, but you can chain them**:

**Method**:
1. Calculate first discount (e.g., 20% off $100 = $80)
2. Copy result ($80)
3. Enter result as "Original Price" for second discount
4. Calculate second discount (e.g., 10% off $80 = $72)

**Example**:
```
Black Friday Sale: 30% off + 10% student discount

Step 1: $100 - 30% = $70
Step 2: $70 - 10% = $63 (final price)
```

**Important**: 30% + 10% ≠ 40% off! Stacked discounts multiply, they don't add.

### Q2: How do I calculate the original price before discount?

**Answer**: **Use Mode 3: "X is Y% of what?"**

**Example**: You paid $60 after a 25% discount. What was the original price?

**Calculation**:
- **Number**: 60 (what you paid, which is 75% of original)
- **Is Percentage**: 75 (because 100% - 25% discount = 75%)
- **Result**: 80

Original price was $80.

**Alternative Approach** (if you know discount amount):
- Discount: $20
- Discount percent: 25%
- Mode 3: 20 is 25% of what? = $80

### Q3: Why does percentage change seem "unfair" in reverse?

**Answer**: **Because percentages are relative to the starting value**—this is mathematically correct!

**Example**:
```
Stock: $100 → $50 = -50% loss
Stock: $50 → $100 = +100% gain

You lost 50%, but need 100% gain to recover!
```

**Why**: 
- 50% loss: Lose half of $100 = -$50
- 100% gain: Gain 100% of $50 = +$50

The *absolute* amounts are the same ($50), but the *percentages* differ because they're calculated from different bases.

**Key Insight**: Percentage changes are not symmetric. This is correct mathematics, not a calculator error.

**Difference is small**: Use whichever is easier for you.
